# ShopDocs

Equipment/document tracking app (FastAPI + MongoDB backend, React frontend), designed to run on-prem on an air-gapped plant network.

## Development
- Backend: `backend/server.py` (FastAPI), deps in `backend/requirements.txt`
- Frontend: `frontend/` (Create React App)

## Deployment
For air-gapped / offline installation, see [`deploy/README.md`](deploy/README.md).
